# Changelog

All notable changes to this module are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the versioning follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-10

First public release.

### Added

- Blocks of links for the footer, each with a heading per language, an option to
  hide the heading, a switch to show or hide the block, and a hook that places it in
  a footer column.
- Links to a category, a content page or an address of your own, with an optional
  caption per language and an option to open in a new tab. Category and content page
  links take their name and address from the catalogue when the page is shown.
- Blocks and links reordered by dragging.
- Polish translation.
